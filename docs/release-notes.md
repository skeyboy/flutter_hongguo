# Hongguo $VERSION 发布日志

## 修改了什么
- 「发现 / 分类」顶部的水平筛选 chip 与「更多筛选」入口页统一到 main 的高亮、滚轮与方向键焦点契约：鼠标与键盘焦点得到同一圈 rim。
- PC 端「更多筛选」页的筛选带改为有高度上限的固定头；带内词表过高时带自身可滚，结果列表始终保留可用视口。
- 发布说明改为读取本文件的三段式结构（修改了什么 / 修复了什么 / 增加了什么），不再由校验脚本内嵌长文本。

## 修复了什么
- 修复 PC / macOS 矮窗口下「更多筛选」页筛选带吃光视口、结果列表无法滑动并触发 `RenderFlex overflow` 的问题。
- 修复发现 / 分类题材 chip 鼠标划入时高亮异常，并移除水平筛选容器上的滚动条视觉提示；滚轮横滑、点选居中与方向键导航保持不变。
- 修复键盘焦点与鼠标高亮不同步：焦点落在 chip 上时得到同样的 rim，并在进入焦点时把 chip 带到行中心。

## 增加了什么
- 新增鼠标滚轮到横向 chip 行的映射，行滑到尽头时把滚轮归还给页面。
- 新增筛选 chip 的方向键焦点导航，以及焦点感知的 `HoverGlow`：观察焦点链但不抢占按钮自身的焦点节点。
- 新增桌面矮窗口滚动、键盘焦点高亮 / 导航、滚轮横滑等回归测试；Android 真机补充「更多筛选」页下滑收起、上滑恢复与题材切换验证。
