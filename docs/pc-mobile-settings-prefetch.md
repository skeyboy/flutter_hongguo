# PC / Mobile UI、预缓存与设置（0.2.0）

本轮全部主实现位于 `flutter_hongguo/packages/`，未覆盖 `imports/` 的独立参考实现。
UI 改造前先落地了 [简要设计与线框](design/pc-mobile-ui.md)，参照用户提供的本地 Web 页面，并按 PC / mobile 特性实现。

## 本轮功能

### 后续 3～5 集自动缓存

- 默认提前缓存 3 集，设置可选 3 / 4 / 5 集。
- 使用滑动窗口，向前切集会保留仍需使用的后续任务，不把整个预缓存队列推倒重来。
- 当前选择优先于排队的后台任务；选中已有后台任务时直接提升同一任务的优先级。
- 已完成的后续文件保持引用，直到移出窗口或交接给前台，避免切集前被缓存淘汰。
- 默认同时准备两项，后台最多占一项；可配置 1～3 项。配置为单项时，正在执行的任务仍需结束或取消，前台优先只针对排队任务。
- 数量和字节预算共同控制淘汰，后台对已知/未知媒体大小均执行预算检查；当前播放文件受保护。
- 后台失败不打断当前播放，也不无限重试；关闭预缓存、换清晰度或退出时释放不再需要的引用。

**不承诺所有网络下零等待**：目标集必须已准备完成，或下载速度足以维持窗口。设置页和播放器显示实际就绪数量。

### 原生 App 设置

| 分组 | 已实现 |
|---|---|
| 播放 | 预缓存开关、3～5 集、并发、默认清晰度、连播 |
| 浏览 | 自动加载下一页、跟随系统/浅色/深色 |
| 缓存 | 数量、空间上限、使用量、清理未使用的文件及孤立半成品 |
| 签名 / 设备 | 本地算法检查、刷新随机签名上下文、显式重建设备编号 |
| 会话 | 掩码 Cookie / x-tt-token、显式保存/清空 |
| 高级协议 | 内容/视频模型域名、协议版本及代码、视频 UA、超时、列表接口签名 |

设置需要保存后生效。默认清晰度在下次打开播放器时生效；预缓存窗口等播放偏好在保存并返回播放器后更新。

签名算法随 App 版本发布，设置调整协议参数与随机上下文；“刷新签名”不代表登录态已刷新。视频内容密钥仍按每集自动解析，不是一个可以通用于所有视频的手填秘钥。

### 下滑自动加载更多

- 接近列表底部约 600px 时自动请求下一页，短首屏会补页直到填满或没有后续。
- 一次只发一个续页请求；切换搜索、体裁、题材时忽略旧响应。
- 按剧目 ID 去重；游标不前进、连续空/重复页或请求失败时暂停自动触发。
- 原位显示加载状态、失败和手动重试；关闭自动加载后保留手动加载按钮。
- 漫剧榜单接入原上游 cell/change 接口，明确标为漫剧榜，使用上游游标分页。

## 配置与会话保存

普通偏好由 `SettingsStore` 使用原子 JSON 文件保存，Cookie/token 放在系统安全存储；JSON 只保存不含凭据内容的引用。

- 会话写入新安全记录后，才提交偏好引用；提交失败会回收新记录，保留旧配置。
- 系统安全存储暂不可用时，不退回明文保存；普通偏好仍可独立更新，原会话引用得以保留。
- 会话只用于内容/模型签名请求，不带给 fallback 或媒体 CDN。
- 域名、版本、容量、并发和换行注入在保存前校验。
- macOS 使用普通 Keychain 模式，无额外共享组；平台依据 [flutter_secure_storage 官方说明](https://pub.dev/packages/flutter_secure_storage)适配。

## 验证记录

本轮的单测与页面测试：核心 113 项、API/缓存 25 项、App 页面/设置 22 项，共 160 项通过。覆盖 390×844、800×900、1280×900，包含配置重启、失败回滚、凭据掩码、主题生效、自动分页与停止重试。

当前 Mac 原生离线集成 3 项通过：

1. 目录→分集→下载→Dart 解密→本地播放器→音轨识别与 seek。
2. 五个后续文件全部 ready；切下一集下载数不增加；改为手机布局保留同一播放器 handle。
3. 系统安全存储对一次性测试记录完成写、读、删除；不读取用户会话进行测试。

真实上游验收：使用《十年恩，一生还》，预缓存后续 3 集，再切到第 2 集。记录到切集阶段仅为“正在排队→已就绪”，没有下载阶段；本次 Mac 准备耗时约 **99 ms**，仍能解码 1080×1920 并 seek 到 10 秒。该耗时是一次具体验收结果，不是通用延迟保证。

结果快照集中在 [本轮证据目录](evidence/pc-mobile-update)，真实播放信息包含公开剧集 ID 和本地文件路径，不含会话、签名头或内容密钥。

## 复测

```bash
./tool/verify_all.sh
./tool/verify_native.sh macos
```

真实上游预缓存测试需显式指定所选剧目与首集 vid，第三个参数为 0（单集）或 3/4/5：

```bash
./tool/verify_mac_live.sh 7697273659248872472 7697275565593611289 3
```

真实测试只准备这一批内容，不被普通离线回归自动执行；此模式为测试临时开启窗口，不改写用户保存的偏好。
