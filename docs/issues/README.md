## 分类口径

- **bug 修复**：现状与预期不符，且能在本仓库内定位到确定的错误分支。
- **优化**：功能已有但不可用/难用，需要新增配置、接线或跨平台适配，不改变对外契约。
- **建议**：需要产品取舍或上游配合，先给出可执行方案与约束，不承诺短期落地。
