# 本地缓存剧目归类

入口沿用首页封面网格：每部剧一张卡片，显示剧名、封面、已缓存集数与体积，按最近缓存时间排序。PC 展示更多列；手机保持两列，支持按剧名搜索。

点击卡片进入本地分集页，按集号排序，展示分集标题、清晰度、大小、占用状态；播放仅访问本地文件。相同视频的不同清晰度作为同一集的多个文件计数，不重复计算集数。保留逐文件删除和占用保护。

详情请求成功即保存合并后的剧名、封面、简介与分集映射，不再等到开始播放。空字段不覆盖已有信息；同剧部分分集资料不抹掉其他分集。目录列表中的资料可补充详情缺失字段。分集 ID 索引用于快速匹配本地文件，资料不随列表快照过期而删除。

封面随正常视频准备缓存到本地，失败使用标题占位图；本地列表与播放不主动联网。封面使用独立体积上限与原子文件写入，不能把会话头转发给图片服务器。

无法确认剧目归属的旧视频放入“待识别视频”，不凭相似标题或相邻视频 ID 合并。提供按剧名搜索补全入口；仅当所选剧目的分集 ID 与本地视频匹配时保存资料并归类。该操作只补全目录，不下载视频。
