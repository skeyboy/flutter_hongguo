# Mac 画中画连播与鼠标交互

| 调整前 | 修改后 | 原因 |
|---|---|---|
| 每集结束关闭系统画中画 | 同一 AVPlayer / 系统小窗替换下一集 AVPlayerItem | 不跳回主窗口，也不重复创建小窗 |
| 鼠标停留选集面板持续显示 | 未固定面板的鼠标活动重置 3 秒计时，移出重新计时 | 移动显示、静止隐藏，释放播放空间 |
| 图标左右键职责不同 | 按主窗口状态决定：隐藏/最小化恢复，可见时展示菜单 | 单次点击只产生一种操作 |

画中画完成事件进入共享 Dart 连播策略，保留自动连播开关、本地分集连续性检查、下载/解密、预缓存、观看记录。下一集准备期间保留结束画面；完成后仅替换原生播放项，主播放器保持暂停，返回主窗口恢复当前分集进度。关闭连播、末集或缓存缺集停留当前小窗；准备失败在主窗口提供重试信息，不循环重试。退出画中画后继续当前集，不重复处理已经上报的结束事件。

播放中鼠标进入、移动或滚动唤出信息，停止活动/移出约三秒后隐藏；Mac 未固定选集面板同样处理。暂停、加载、错误、正在拖动、弹出菜单、键盘导航及无障碍模式保留必要操作。固定选集面板仍遵守用户固定选择。手机/TV 的触摸和遥控器行为不变。

菜单栏用窗口 isVisible / isMiniaturized 与应用隐藏状态判断；后台但仍可见的窗口点击展示菜单，只有隐藏或最小化时点击恢复。Dock 恢复逻辑独立保留。

## 验证记录（2026-10-21）

- 应用单元/组件测试：143 项通过，1 项条件跳过。新增鼠标静止/移出计时、未固定选集面板、画中画换集与旧事件隔离、旧回调清理、全屏请求串行化测试。
- Mac 原生集成验证 4 项：主窗口隐藏后三个本地分集在同一系统画中画中连续播放，主播放器始终暂停；末集实际播放到结束后停留小窗；再次进入/退出与窗口最小化；真实关闭/恢复、菜单栏恢复决策、设置往返样式；鼠标唤出、全屏 Esc 与退出页面。最后几项分属现有窗口与沉浸用例。
- 为排除同名 App / 构建目录干扰，原生用例使用独立的 PRODUCT_NAME 与 bundle ID；Dart/Swift 功能源文件与主项目逐字节核对一致。主项目保持原应用名称及标识。
- 可见/隐藏状态和进度通过真实 AppKit / AVKit 回调验证。系统菜单栏使用原生窗口状态验证点击决策，未自动点击系统菜单栏图标。
- 测试等待原生释放完成后再创建下一播放器；画中画进度轮询使用真实事件等待，避免依赖被遮挡/隐藏窗口的渲染帧。全屏切换等待 didEnter/didExit 完成回调，退出页面和进入小窗也等待未完成的窗口切换。
