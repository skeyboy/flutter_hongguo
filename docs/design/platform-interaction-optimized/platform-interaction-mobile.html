这个原型验证什么

切换手机、iPad 竖横屏和分屏，再进入详情、播放器、筛选弹层与设置。播放器支持单击显隐、双击中央播放、左右双击快进退、长按 2×、触控上下滑切集；弹层可从把手直接拖走。

BeforeAfterWhy
小屏把桌面控件硬塞进同一行主操作常驻，次级操作按宽度渐进披露横竖屏与分屏都保留可达性
弹层只能点按钮关闭支持系统返回、遮罩与可打断的拖拽关闭符合触控设备的直接操作预期
播放器点击/双击/长按/滑动互相抢占并行识别意图，位移阈值后取消失败者手势不迟滞，也不误触切集
iPad 只按 mobileHost 处理竖屏 Rail、横屏宽播放器、分屏自动回退底部导航形态变化时交互仍稳定
移动端缺少独立「分类」入口顶部 / 底部导航均为发现 → 分类 → 榜单 → 我的 → 设置；分类页筛选状态独立于发现页与 PC / iPad 导航和信息层级一致，又不覆盖发现页筛选
顶部筛选平铺，看不出层级依赖发现 / 分类页均改为一级内容类型在上、二级题材在下，切换一级联动换词表并清空失效二级值；层级由位置与联动体现，不展示「主 / 从」引导话术标签词表来自真值分域数据（真人剧 29 / 漫剧 8 / AI剧 8），题材不伪造过滤并明示
筛选只能逐项点击，跨级切换要来回找按钮左右滑动：二级优先切项；二级到边界后一级沿同方向切一次；两级均到边界则给出「无可切换项」反馈一次手势即可跨级浏览，左 / 右规则对称，键盘方向键等价
设置反馈停留在内容顶部保存反馈在安全区上方常驻可见从页面底部保存也能确认结果
