这个原型验证什么

用方向键移动焦点，Enter / Space 确认，Backspace / Esc 返回。进入播放器后，焦点顺序是“画面 → 控制栏 → 快进退预览”；进入选集面板后，Back 只关闭面板并回到选集按钮。

BeforeAfterWhy
隐藏 / Offstage 控件参与几何计算只遍历可见、可聚焦、非 inert 的节点焦点不会跳进不可见页面
焦点请求后直接判定移动成功目标先确认可见性，再滚动进入视口并聚焦页尾和嵌套滚动不会丢焦点
selected 同时表达焦点和开关状态蓝色焦点环、红色选中项、aria-checked 开关三者的语义分离读屏与视觉反馈一致
播放器方向键全局抢占，面板与控件也受影响画面、控制栏、快进退预览、选集面板各有状态遥控操作可预测、可取消
设置页最后一项之后 primaryFocus 变空焦点始终保留在最后可达项，焦点变化先 ensureVisible设置页尾可继续操作
TV 缺少独立「分类」入口导航补发现 → 分类 → 榜单 → 我的 → 设置；分类页三轴与 PC 同款并保留 tv-focus 三态与 PC / iPad 对齐，遥控仍按几何焦点 + Back 层级操作
