# 筛选、主题与本地缓存体验改进

## PC 与 mobile

PC：搜索栏保持置顶，其下增加常驻的横向筛选工具栏。可直接切换推荐/最新/榜单、内容类型、题材和排序。空间不足时横向滚动，不挤占内容区。

Mobile：保留紧凑的置顶工具栏，提供列表类型、内容类型与筛选入口；点击筛选打开底部面板，确认后应用。完整品牌与搜索区可随内容滚走，筛选能力始终可达。筛选变化回到列表顶部。

主题：选择浅色/深色/跟随系统后立即保存并更新全局主题，保留其他尚未保存的表单字段；写入失败明确反馈。其他设置通过保存应用，验证持久化和运行时行为。

## 内容缓存

参考 hack-news-flutter 的 LocalCache/CacheStore 分离思想：保存带时间的有序列表快照（包含下一页游标），按页面、搜索词、类型、题材、排序、榜单隔离。先读快照显示，再请求网络；新数据替换旧快照，失败保留旧内容并提供刷新入口。不混合新第一页和旧分页游标。切页/切筛选的过期异步结果不覆盖当前页面。

原生使用应用私有目录 JSON 原子写入，不增加平台数据库插件；内存缓存供同进程快速切换，磁盘支持重启。保留最近 80 个列表、每列表至多 500 条、最长 7 天。达到单列表上限时不保存截断后游标，避免遗漏。写盘失败保留本轮网络结果并提示。

## 本地视频

设置 → 缓存管理 → 本地缓存剧集。列出具有完整大小清单的 MP4，展示剧名/集号（有目录元数据时）、vid、清晰度、大小及使用状态。可直接播放本地文件和逐项删除；播放/预缓存占用项禁止删除。旧版本缺少目录元数据的缓存仍显示 vid，不伪造剧名。未完成文件不列入已缓存剧集。

此入口直接使用本地文件，打开和播放无需再次查询上游。目录快照与视频文件是不同缓存；视频清理不删除目录快照。
