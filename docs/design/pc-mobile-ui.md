# PC / Mobile UI 简要设计（实施前草案）

日期：2026-10-19。目标工程：`flutter_hongguo/packages/` 主 workspace。
参照：用户提供的 [本地 Web 页面](http://127.0.0.1:8000/ui)。本草案先于本轮响应式 UI 改造落地；缓存调度与设置存储的底层工作沿用本轮已开始的实现。

## 1. 已观察到的 Web 模式

- 顶部为品牌、推荐/榜单/最新/筛选、搜索框、历史/收藏/主题/密钥工具。
- 深色背景、红色强调、圆角选项，竖版海报配标题/集数/简介；列表密度较高。
- 筛选页有短剧/漫剧/AI短剧、时间与排序选项，显式应用筛选。
- 页面末尾有“加载更多”；实际列表存在重复条目，Flutter 分页需按 ID 去重。
- Web 的链路密钥是 Node 服务鉴权。原生 App 的系统会话凭据、签名参数、每集内容密钥并不是同一个对象，设置页不能混为一栏。

沿用信息分组、海报比例、红色强调及主题切换语义；按设备改写导航和播放器布局。历史/收藏不在本轮新增范围，不放置无效入口。

## 2. 本轮功能范围与信息架构

主导航：**发现 / 分类 / 设置**。

- 发现：推荐、榜单、最新；全局搜索；短剧/漫剧/AI短剧切换。
- 分类：体裁、题材与排序；PC 展开，Mobile 以筛选抽屉/底部面板收纳。
- 设置：播放与预缓存、缓存容量、系统安全存储会话、设备/签名状态、高级接口参数、主题与自动分页。
- 详情：简介、真实分集、开始观看。
- 播放：本地文件播放、选集、清晰度、连播、后续 3～5 集预缓存状态。

上游榜单是漫剧榜，UI 明确显示“漫剧榜单”，不把它标成其他体裁排行。（2026-10-27 更新：这条要求的现实现是标题「漫剧 · 推荐榜 / 漫剧 · 热播榜 / 漫剧 · 新剧榜」——漫剧的归属仍然写在标题里，但不再靠把共享的一级改写成「漫剧」来表达；见 `discover-catalog-cascade-tabs.md` §5 末条。）

## 3. 断点与布局

| 尺寸 | 主导航 | 列表 | 播放 | 设置 |
|---|---|---|---|---|
| `<720`（手机） | 底部 NavigationBar；顶部紧凑品牌/搜索 | 两列竖版封面，触控目标 ≥48；不放大幅宣传横幅挤占首屏 | 黑色沉浸画面；底部一行＝播放/暂停 + 通栏进度（时间戳单独一行）+ 倍速 + 选集；点按唤出、双击半屏 ∓10s、长按 2× 临时快进；选集用可滚动底部面板 | 全屏分组列表，高级项折叠，保存固定在顶部 |
| `720～1099`（平板/窄窗） | 紧凑 NavigationRail | 自适应 3～5 列，保持每张封面可读 | 窄/竖向沿用手机；横向空间足够时双栏 | 保留分组，适度限宽 |
| `≥1100`（PC） | 固定侧栏，发现/分类/设置 | 网格、常驻搜索和内联筛选；首屏直接看内容 | 左视频 + 右选集；键盘 Space/K 播放、←/→ ±5s、J/L ±10s、↑/↓ 音量、M 静音、PageUp/PageDown 切集、F 全屏、I 选集；鼠标悬停显示控件，单击画面切播放 | 左分组导航 + 右侧限宽表单；键盘可遍历 |

尺寸改变只改布局，不重建播放器或重新下载。

## 4. 三项核心交互

### 4.1 滑动窗口预缓存

- 默认开启，默认后续 3 集，可选 3/4/5；不是每次切集重新清空全部任务。
- 当前播放优先；选择已排队的预缓存集时，把同一任务提升为前台，复用已下载结果。
- 预缓存完成的文件保留 lease/pin，直到窗口移出或前台取得自己的引用，避免切集前被淘汰。
- 向后/向前跳集、改清晰度、关闭预缓存、退出播放器时，释放不再需要的窗口任务；保留可复用的目标集与后续集。
- 默认两条准备槽位，后台最多一条，给当前播放留出位置；设置可选 1～3 条。
- 分集显示准备中/已缓存；后台失败不覆盖当前播放错误，不无限自动重试。
- 容量与网络不足时如实显示已完成数量，不承诺所有网络下零等待。

### 4.2 设置

普通偏好与会话密钥分开保存；会话使用系统安全存储，普通 JSON 不含 Cookie/token。

| 分组 | 配置/操作 |
|---|---|
| 播放 | 预缓存开关、3/4/5 集、并发、默认清晰度、连播 |
| 浏览 | 自动加载更多、跟随系统/浅色/深色 |
| 缓存 | 空间和数量上限、用量、清理未使用文件 |
| 签名与设备 | 本地算法检查、刷新随机签名上下文、显式重建设备编号 |
| 会话 | 掩码 Cookie / x-tt-token、保存/清空；不转发 CDN/fallback |
| 高级 | 接口域名、协议版本/代码、视频 UA、超时、列表签名 |

刷新签名上下文不等于刷新账号登录态；算法更新随 App 版本发布。每集视频内容密钥自动从响应解包，不暴露为用户手填的“通用秘钥”。

### 4.3 自动加载更多

- 到达尾部前约 600px 自动请求；短页面布局后补页，直到填满可视区域或无后续。
- 同时只发一个续页请求；旧筛选/旧搜索响应不能覆盖新页面。
- 按 ID 去重；游标不前进或连续空/重复页时停止自动请求并保留手动重试。
- 底部显示局部加载，不用全屏 spinner 或把列表滚回顶部；关闭自动加载时保留手动入口。

## 5. 状态与可访问性

- 初次加载用骨架；首屏失败、分页失败、空结果、后台预缓存失败分别展示。
- 降低动态效果；不做卡片入场队列。选择反馈使用系统 Material 动效，尊重系统减少动画设置。
- 明暗主题共用颜色语义，不把固定浅色背景/文字带进深色界面。
- 桌面键盘与手机触控各有入口，不依赖 hover 才可操作；底部面板保留安全区。

## 6. 对应代码与实施顺序

1. `packages/core/lib/src/config/app_settings.dart`：共享偏好与参数验证。
2. `packages/api/lib/src/media_cache.dart`：优先级、并发与容量。
3. `packages/app/lib/settings/`：偏好事务与系统会话存储。
4. `packages/app/lib/playback/prefetch_window.dart`：可测试的窗口生命周期。
5. `packages/app/lib/features/`：按上述 PC/Mobile 方案改造列表、设置与播放器。
6. 补充调度、窗口、设置、自动分页和断点测试，再以当前 Mac 做原生回归。

验收至少覆盖 390×844、800×900、1280×900 三种宽度；缓存任务复用/晋升、配置重启恢复、分页错误不无限重试、播放器布局切换不重启任务。
