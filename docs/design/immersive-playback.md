# 沉浸式播放与后台能力提醒

播放页铺满视频，不使用 AppBar、侧边导航或底部导航。标题和退出入口在安全区域内覆盖画面，底部一条通栏进度 + 左右两簇按钮：左簇＝播放/暂停、±10s、上一集/下一集、音量（桌面宽面）、`当前/总时长`；右簇＝选集、清晰度（宽面/横屏）、倍速、可用时的投屏与悬浮播放、全屏。宽度不够时按固定顺序丢件，播放/暂停、选集、倍速、全屏永不丢弃。所有控件共享显隐计时器，显隐和选集面板均不改变视频矩形、不重建 Player。形态规格见 [播放控制条重构](player-controls-redesign.md)。

| 场景 | 行为 |
|---|---|
| 连续播放、无交互 | 3 秒后隐藏标题、退出入口及底部操作；140ms 淡出 |
| 手机点按画面 | 隐藏时第一次点按只唤出操作，不意外暂停；已显示时点空白收起 |
| PC 单击画面 | 切换播放/暂停（唤出靠鼠标移动，不靠点击）；两端双击中心同样切播放，双击左/右半屏 ∓10s |
| PC 鼠标进入或移动 | 立即显示，停止移动后重新计时；隐藏时不显示视频区鼠标指针 |
| 暂停、加载、错误、弹窗、选集打开、拖动进度 | 保持操作可见；恢复播放且操作结束后再计时 |
| 键盘或辅助功能 | Tab 唤出并保持可操作；键盘显隐和减少动画模式不加动效 |
| 返回 | 标题左侧为退出页面；系统返回优先关选集、再退出全屏、最后返回页面 |
| 全屏 | F 进入、Esc 退出；不复制播放器路由，选集仍可使用，视频句柄保持不变 |
| 手机全屏 | 尊重当前方向，不强制把竖屏短剧旋转为横屏 |
| 系统 PiP | 使用系统交互，不叠加本页标题和应用操作 |
| 桌面小窗 | 同样自动隐藏操作，唤出后可恢复原窗口或退出页面 |

播放进度、音量（桌面宽面）、倍速、清晰度与连播仍保留。清晰度进了控制条右簇（宽桌面与手机横屏），此时选集面板里不再重复一份下拉；控制条放不下清晰度的面（窄窗、手机竖屏）仍由选集面板那一行承担——同一个状态只留一个入口。连播和分集集中在选集内；播放设置位于选集面板固定标题行的齿轮按钮中；去掉单独的更多菜单。可用时悬浮播放保留直接图标，避免恢复小窗需要绕行。菜单打开时暂停隐藏计时。

## 设置立即生效

移动端后台播放、后台下载及悬浮播放开关在切换时单独确认，开启和关闭均说明影响。确认后只保存这一项，留在设置页，不要求再次点保存；取消不改变状态。未保存的主题以外表单草稿不被顺带写入。其他配置仍按保存按钮提交，PC 保留原有显式保存方式。

手动开关选择也被视为明确决定，之后不再推荐重新开启该项。保存失败保留原值并显示错误。系统下载通知授权仍由系统单独决定。

## 从后台返回时推荐

仅移动端：已经播放过视频，且播放页从真实后台回到前台时，等视图恢复 800ms 后检查。未播放、加载失败、其他页面或已有对话框时不弹。

1. 优先检查后台播放：未开启且从未询问时，只推荐这一项。
2. 之后的另一次返回，可推荐尚未开启、未询问过的小窗播放；先查询原生 PiP 支持，不支持则不弹。
3. 两次推荐至少间隔 1 分钟，同一次返回只出现一个，不串联对话框。已开启的能力跳过。
4. 开启或“暂不开启”都持久化已询问状态，跨剧集、页面和重启不重复。确认只启用能力，不自动进入小窗，也不擅自恢复已暂停的视频。
5. 用户主动进入 PiP 的切换不触发额外推荐。后台下载不参与播放页推荐，只在设置页由用户选择。

内部状态 `backgroundPlaybackPrompted`、`floatingPlaybackPrompted` 不进入协议签名参数。旧配置缺少这些字段时默认为尚未询问。

## 验证重点

- 真机/模拟器保留实际分辨率，隐藏和恢复标题/退出时视频矩形、Player 句柄不变。
- 真实鼠标、触控与键盘恢复路径；隐藏控件不接收点击、焦点或辅助功能访问。
- 开关确认/取消、草稿隔离、提示记录持久化与冷却、设备不支持 PiP 时不建议开启。
- 后台播放、系统 PiP 与后台缓存继续执行原有独立设置，不因 UI 隐藏暂停。

验收日志保存于 `docs/evidence/immersive-playback/`。桌面虚拟尺寸测试、手机实际窗口测试及模拟生命周期测试分开记录。

## 视频优先的选集与设置入口

| Before | After | Why |
| --- | --- | --- |
| 顶部标题重复显示集号 | 14px 普通字重、半透明名称，保留白色返回按钮 | 名称弱化但退出入口明确；集号继续在底部选集入口展示 |
| 更多菜单和选集分离 | 设置齿轮放在选集面板顶部，滚动分集时始终可见 | 低频配置统一入口，保留常用进度与倍速 |
| 手机选集占 72% 高度 | 竖屏底部面板占 65%，保留拖动关闭和返回键 | 留出更多视频可见空间，触摸目标仍为标准按钮尺寸 |
| 横屏容易被系统边缘遮挡 | PC/横屏右侧覆盖抽屉增加安全区域 | 不挤压视频，适配横屏刘海与边缘手势 |

PC 鼠标唤出控件、Esc/外部点击收起；手机点击画面唤出，竖屏底部面板、横屏覆盖抽屉。选集初始关闭，PC 可主动保持展开，随时可关闭释放空间。播放设置打开前先关闭选集，返回设置后直接回视频，不遗留遮挡面板；倍速和桌面音量仍可直接调整。设置复用现有配置页，不复制一套偏好存储。

设计参考：[Apple TV Mac 播放控件](https://support.apple.com/en-nz/guide/tvapp-mac/atv31d6caa7/mac)、[YouTube 全屏交互](https://support.google.com/youtube/answer/72689)。上述面板合并是本项目适配设计，不代表这些产品采用完全相同布局。
