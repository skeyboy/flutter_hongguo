# macOS 内容优先播放

| 调整前 | 调整后 | 原因 |
|---|---|---|
| hidden 事件沿用手机后台开关，遮挡即暂停 | 桌面窗口遮挡、最小化不暂停，也不取消正在准备的播放 | 桌面多任务不应中断播放；用户主动暂停仍保留 |
| 缩小主窗口作为小窗 | AVKit 系统画中画，播放页直接入口 | 保留原窗口尺寸，系统管理跨应用浮窗 |
| 通用控制栏 | 黑底、底部标题与时间轴、自动隐藏控件 | 对齐 TV 的内容层级，鼠标与快捷键适配桌面 |

## 状态与交互

Mac 画中画使用已解密的本地 MP4 交接到 AVPlayerLayer。交接前暂停 media_kit，失败恢复原播放状态；退出按系统返回的时间和播放状态恢复，避免双音轨。系统播放进度持续写入观看历史。手动关闭播放页则释放两套播放器。入口首次点击即启用应用自身画中画设置，不影响手机默认值；在设置关闭后退出小窗。

播放页没有普通导航栏；左上返回，底部标题、选集、音量、倍速、画中画、全屏。播放时鼠标移动唤出，静置三秒淡出；暂停、菜单和选集面板保持可见。选集仍为覆盖层，关闭释放整个视频空间。窄窗口减少辅助按钮，保留播放、选集、画中画和全屏。系统画中画期间原窗口提供返回入口，不重复播放。

桌面后台播放是固定行为，不再暴露无效的后台播放开关；移动端后台策略保持独立。自动连播与预缓存同样允许在桌面窗口遮挡时继续。

设计参考：[Apple TV Mac 画中画](https://support.apple.com/en-gb/guide/tvapp/atvb71d09d11/1.0/web/1.0)、[IINA](https://iina.io/)。采用内容优先、指针唤出与系统小窗交互，不复刻 TV 遥控器焦点。

## 验证记录（2026-10-21）

- Flutter 静态分析与 135 项应用测试（另有 1 项条件跳过）；新增桌面/手机后台策略，以及 Mac 文件 URL 编码、失败回退、原生进度和暂停状态恢复测试。
本机 macOS 27.0.1 原生集成测试 4 项通过：

1. 缓存跨清晰度连播、手动切集及末集停止。
2. 首次点击真实 AVKit 画中画：时间推进、主播放器暂停、返回继续、倍速保留；原窗口尺寸保留、真实最小化继续播放、手动暂停保留。
3. 播放准备期间的后台策略，桌面无需手机后台播放开关。
4. 沉浸播放：鼠标唤出、控件自动隐藏、暂停保留操作、全屏 Esc 退出、返回原页面，视频播放器实例保持不变。

修复全屏切换时 Flutter 焦点暂时回到根节点造成 Esc 无效；监听原生窗口全屏与聚焦事件，保留当前播放页的 Esc 兜底。
使用本地加密测试片段经过现有 Dart 下载/解密链路验证，不依赖线上节目。手机与其他桌面平台仅运行共享逻辑回归，本轮不宣称完成这些平台的设备验收。
