# 浮层筛选与播放空间优化

## 最终交互原则

所有尺寸下，选集都不预留侧栏或底部布局高度。视频始终占满 AppBar 以下的可用区域；显隐只影响上层控件。宽桌面也默认隐藏选集，不因“屏幕大”自动占用播放空间。

| 场景 | 交互 |
|---|---|
| 发现/分类 | 常驻筛选入口下使用 Stack 覆盖面板；展开不移动列表、不改变滚动位置。外部遮罩点击仅关闭面板，不误开资源。 |
| PC 与平板横屏 | 右侧覆盖抽屉，宽度不超过 340px / 窗口宽度 80%；点击顶部选集或 I 键打开，Esc、关闭按钮、外部点击关闭。 |
| “保持选集展开” | 只阻止自动收起，仍为浮层，绝不变成占空间的固定侧栏；用户可随时关闭。仅本次页面保存。 |
| 手机竖屏 | 选集由底部面板展示，选中后关闭，也可显式关闭。浏览列表时不按计时器强行收起。 |
| 手机播放操作 | 底部操作覆盖视频，支持手动隐藏；播放中闲置 5 秒自动隐藏，触碰画面再显示。顶部选集入口始终可达。 |

桌面临时抽屉在播放中闲置 5 秒自动收起。鼠标悬停、键盘操作、暂停、加载、错误或无障碍导航时不自动关闭；离开后重新计时。选中分集后收起，保持展开模式例外。抽屉内部全部可滚动，避免矮窗口中控件挤掉分集列表。

切换布局不创建新 Player，不重新下载；保持当前播放位置、清晰度与本地连播。缺集或音频提示也会在视频上方显示，避免隐藏选集后看不到提示。

## 参考与取舍

参考 QuickTime 的画面/屏上控件分离、操作时显露的方式，以及 Plex 的可收起导航思路；这里的 5 秒、340px 和窗口断点是本项目设计值，不代表这些产品的原有参数。

- https://support.apple.com/guide/quicktime-player/open-and-play-a-file-qtp6cee0761b/mac
- https://support.plex.tv/articles/navigating-the-big-screen-apps/

不使用默认占位侧栏；不自动从视频中央弹出选集；不在用户滚动或键盘选择时隐藏；不依赖 hover 才能找到入口，以兼容触屏 PC。
