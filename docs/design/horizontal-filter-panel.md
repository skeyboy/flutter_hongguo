# 水平筛选展开面板方案

状态：已实施，48 项 App 测试与 3 项 Mac 原生集成通过。基于当前 `packages/app/lib/features/library_page.dart` 的常驻筛选工具栏、DropdownButton 和手机底部筛选表单分析。（2026-10-27：本文件的「展开面板」这一形态已被就地胶囊行 + 常驻题材栏取代，见 `pc-mobile-theme-rail.md` 与 `discover-catalog-cascade-tabs.md`；接口约束那一节仍然有效，下面按新措辞更新过一条。）

## 建议结论

采用“常驻筛选入口 + 入口下方横向展开面板 + 即点即切换”。面板在当前内容区域展开，不使用纵向下拉列表，也不从手机屏幕底部弹出。PC 与手机共享相同筛选状态和交互语义，只调整密度与溢出方式。

选项水平排列指每个筛选维度内的按钮横向排列；不同维度保留分组行，避免把频道、题材、排序混成无法辨认的一长排。

发现页展示频道选项；分类页不重复展示频道。手机也可在同一面板展示发现页的频道行，打开对应入口时滚动/定位到该行。

## PC 与手机适配

| 项目 | PC（≥720px） | 手机（<720px） |
|---|---|---|
| 展开位置 | 筛选工具栏正下方，宽度跟随视频内容区 | 工具栏正下方，占满可用内容宽度 |
| 面板形态 | 轻边框、圆角、弱阴影，通常 180～260px | 紧凑分组，通常 200～280px，不弹出大面积遮罩 |
| 按钮排列 | 横向 Wrap，题材较多可换行 | 横向按钮行；题材过多时横向滑动，并提示还有选项 |
| 高度上限 | 可用内容高度的 40% | 可用内容高度的 50%，不是固定屏高 |
| 极端情况 | 大字体/窗口矮时面板内部滚动，保留收起入口 | 必要时面板内部纵向滚动，避免溢出；不缩小触控目标 |
| 操作方式 | 点击、Tab、方向键移动焦点、Enter 选择、Esc 收起 | 点击与水平滑动；系统返回优先收起面板 |

建议触控按钮高度至少 44px，横向间距约 8px。较长题材名保留可读宽度，不强行等分所有按钮。键盘聚焦选项时滚动到可见位置。

## 展开和选择规则

1. 点击任意筛选入口，打开同一个完整面板，并突出对应分组；同时最多一个面板。
2. 打开时显示所有有效筛选维度，不要求逐个打开下拉菜单寻找选项。
3. 点击另一入口，只切换面板中的关注分组；再次点击当前展开入口收起。
4. 点击选项立即更新选中标记和入口摘要，保持面板打开，方便连续选择。无需“应用筛选”。
5. 再次点击当前已选项不请求网络；“全部题材”用于清除题材限制。
6. 点击“收起”、面板外区域、PC Esc 或手机返回收起面板；已经生效的选择不会回滚。
7. 面板打开时，外部第一次点击用于关闭，不同时触发下方视频进入播放。
8. 不同时提供含义不明确的“全部重置”：保留每组自己的默认选项，避免误清频道、搜索或内容类型。

选中态同时使用颜色、对勾和语义 selected 标记，不能仅凭颜色区分。面板展开/收起使用约 180ms 动画；系统减少动态效果时关闭尺寸动画。

## 频道与接口约束

- 普通推荐：类型、题材、排序均可用，每组单选。
- 最新：排序固定为最新上架；不能让入口显示“最新”而实际按热度返回数据。
- 榜单：当前 API 是漫剧榜单（`packages/api/lib/src/catalog.dart:498-515` 三档全部是 `comic_series_*`）。显示推荐榜/热播榜/新剧榜；漫剧这个归属写在标题里（「漫剧 · 推荐榜」…），不展示无效的短剧、题材和普通排序选项。2026-10-27 起它不再顺手把共享的一级类型改写成漫剧——那会让另一页的分类被看不见地换掉类型，见 `discover-catalog-cascade-tabs.md` §5 末条。
- 分类：显示类型、题材、排序。
- 搜索：当前搜索接口没有实现这些分类过滤；不展示看似可选但实际不生效的筛选组，保留搜索词与清除搜索入口。
- 更换类型时清除不适用的旧题材，异步加载新题材；显示加载/失败重试，旧类型的响应不能覆盖新选项。

“全部按钮”是全部适用选项均可在一个面板中访问，不代表把无效参数也显示成可用。

## 与缓存和列表刷新结合

- 选择态立即变化；缓存命中时立即展示对应快照。
- 连续选择在约 250ms 后合并成一次网络刷新，减少来回点击触发的多次请求。
- 刷新期间保留旧内容及轻量加载提示；如果仍是旧条件的内容，标明正在更新，不误认为筛选无效。
- 暂停自动分页，直到新条件第一页及游标确定；沿用 revision 丢弃过期响应。
- 工具栏与面板位于稳定区域，下方列表独立滚动。切换选项只把结果列表回到起点，不让入口随页面 jumpTo(0) 上下跳动。
- 收起面板不再发起额外请求。

## Flutter 实现建议

拆分 `CatalogFilterBar`、`CatalogFilterPanel` 与不可变的筛选状态。PC 与手机共用面板和事件，避免两套选择状态分别保存在下拉菜单和底部表单中。

使用 TextButton/ChoiceChip/Wrap/横向 SingleChildScrollView 组成按钮组，AnimatedSize 控制展开。保留现有 CatalogRepository、列表快照与分页规则；请求逻辑由同一筛选状态生成。面板不新增路由，也不修改播放器生命周期。

## 验收标准

- 滚动后入口仍可用，展开面板稳定贴在入口下方。
- PC 和手机均没有纵向下拉菜单；手机没有从屏幕底部弹出的筛选表单。
- 单击选项立即变化，面板不自动关闭，无额外确认步骤。
- 所有适用选项可以到达；长题材、大字体、小窗口不溢出。
- 排行榜、最新、分类和搜索各自只显示有效选项。
- 连续切换不混入旧游标数据，命中缓存时不先清空页面。
- 返回/Esc/外部点击仅收起面板，不误开视频或回退页面。
